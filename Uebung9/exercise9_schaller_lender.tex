\section*{9.1: Shannon entropy for binomial distribution}
\subsection*{(a)}
The Shannon entropy
\begin{align}
H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)
\end{align}
is defined for a discrete variable $X$ and a probability distribution $P(x)$.
We use the following python function in a jupyter notebook to calculate the entropy:
\begin{minted}{python}
import numpy as np
from scipy.stats import binom, norm

def shannon_entropy_binomial(n, p=0.5):
    k = np.arange(0, n + 1)
    probabilities = binom.pmf(k, n, p)
    return -np.sum(probabilities * np.log2(probabilities))
\end{minted}

    We obtain the following entropies:
    \begin{align}
H (n=1) &= 1 \text{ bit} \\
H (2) &= 1.5 \text{ bit} \\
H (4) &= 2.0306 \text{ bit}  \\
H (8) &= 2.5442 \text{ bit}
    \end{align}
\subsection*{(b)}
For $p=\frac{1}{2}$ we obtain the following probability distribution:
\[
P_n(k) = \binom{n}{k} \left(\frac{1}{2}\right)^n = \frac{n!}{k!(n-k)!} 2^{-n}
\]
With the natural logarithm, we obtain a form where we can use the Stirling approximation:
\[
\ln P_n(k) = \ln(n!) - \ln(k!) - \ln((n-k)!) - n \ln 2
\]
Using the Stirling formula $\ln(N!) \approx N \ln N - N$, we approximate this equation to
\begin{align}
    \ln P_n(k) & \approx \left[n\ln n - n \right] - \left[k\ln k - k\right] - \left[(n-k)\ln(n-k) - (n-k) \right] - n \ln 2 \\
               & \approx n\ln n - k\ln k - (n-k)\ln(n-k) - n\ln 2
\end{align}
For the Taylor expansion around the maximum $k_{max} = n/2$ for $f(x) = \ln P_n(x + n/2)$, we shift $\ln P_n(k)$ by $x = k - n/2$ and calculate some derivatives:
\begin{align}
f(x) &\approx n\ln n - \left(\frac{n}{2}+x\right)\ln\left(\frac{n}{2}+x\right) - \left(\frac{n}{2}-x\right)\ln\left(\frac{n}{2}-x\right) - n\ln 2 \\
f'(x) &= -\ln\left(\frac{n}{2}+x\right) - 1 + \ln\left(\frac{n}{2}-x\right) + 1 = \ln\left(\frac{n}{2}-x\right) - \ln\left(\frac{n}{2}+x\right) \\
f''(x) &= - \frac{1}{\frac{n}{2}-x} - \frac{1}{\frac{n}{2}+x} \\
f(0) &\approx n\ln n - n\ln\left(\frac{n}{2}\right) - n\ln 2 = n\ln n - n(\ln n - \ln 2) - n\ln 2 = 0 \\
f'(0) &= \ln\left(\frac{n}{2}\right) - \ln\left(\frac{n}{2}\right) = 0 \\
f''(0) &= - \frac{2}{n} - \frac{2}{n} = - \frac{4}{n}
\end{align}
With this values, we have all coefficients to perform the Taylor expansion until second order:
\begin{align}
    f(x) \approx 0  +  0 \cdot x - \frac{4}{n} \cdot  \frac{x^2}{2} = - \frac{2 x^2}{n}
\end{align}
The exponential of this results in our new approximation for the binomial distribution:
\begin{align}
    P_n(x) \approx C \exp^{-\frac{2 x^2}{n}}
\end{align}
We now have to normalize this continous distribution to obtain the correct factor $C$:
\begin{align}
    \int_{-\infty}^{\infty} P_n(x) \, dx &= 1 \implies C \int_{-\infty}^{\infty} e^{-\frac{2x^2}{n}} \, dx = C \sqrt{\frac{\pi n}{2}} = 1 \\
    C &= \sqrt{\frac{2}{\pi n}} \\
    P_n(x) &= \sqrt{\frac{2}{\pi n}} \exp^{-\frac{2 x^2}{n}}
\end{align}
The approximation and the exact distribution are plotted in Fig. \ref{figBinomial} for $n=50$.

\subsection*{(c)}
The continous entropy with the natural logarithm is:
\begin{align}
    H &= -\int_{-\infty}^{\infty} p(x) \ln p(x) \, dx = -\int_{-\infty}^{\infty}  \sqrt{\frac{2}{\pi n}} \exp^{-\frac{2 x^2}{n}} \left( 0.5 \ln \frac{2}{\pi n} - \frac{2 x^2}{n} \right) dx \\
      &= - 0.5 \ln \frac{2}{\pi n} + \sqrt{\frac{2}{\pi n}} \frac{2}{n}  \left[ \int_{-\infty}^{\infty} \exp^{-\frac{2 x^2}{n}} x^2 dx \right] \\
      &= - 0.5 \ln \frac{2}{\pi n} + \sqrt{\frac{2}{\pi n}} \frac{2}{n} \left[ \sqrt{\frac{\pi n}{2}} \frac{n}{4} \right]\\
      &= - 0.5 \ln \frac{2}{\pi n} + \frac{1}{2} \\
      &=  0.5 \left( \ln n + \ln \frac{\pi}{2} + 1 \right)
\end{align}
If we want to convert this result into bit units, we have to multiply it with $\frac{1}{\ln 2}$ and obtain:
\begin{align}
    H_{bit} &=  0.5 \left( \frac{\ln n}{\ln 2} + \frac{\ln \frac{\pi}{2}}{\ln 2} + \frac{\ln e}{\ln 2} \right)
            &=  0.5 \left( \log_2 n + \log_2 \frac{\pi}{2} + \log_2 e \right)
            &=  0.5 \log_2 n + C
\end{align}
The result is compared with the exact Shannon entropy in \ref{figBinomial}. We observe good agreement.

\section*{9.2 Generating function}
\subsection*{(a)}
To solve this task, we recall the general binomial formula and the geometric series:
\begin{align}
    (a + b)^n = \sum_{k=0}^{n} \binom{n}{k} a^{n-k} b^k
    \frac{1}{1 - q} = \sum_{k=0}^{\infty} q^k
\end{align}
Applying this on the given examples for $f(x)$, we obtain
\begin{align}
(1 + x)^n = \sum_{k=0}^{n} \binom{n}{k} 1^{n-k} x^k \implies a_k = \binom{n}{k} 1^{n-k}
\frac{1}{1 - bx} = \sum_{k=0}^{\infty} (bx)^k \implies a_k = b^k
\end{align}

\subsection*{(c)}
The generating function for $h(x)$ is a Cauchy product of two series
\begin{align}
    h(x) = \left( \sum_{i=0}^{\infty} a_i x^i \right) \cdot \left( \sum_{j=0}^{\infty} b_j x^j \right)
\end{align}
If we multiplicate this properly and use the rule for the Cauchy product, we obtain
\begin{align}
    h(x) = \sum_{i=0}^{\infty} \sum_{j=0}^{\infty} a_i b_j x^{i+j}
\end{align}
Now we have to reorganize the sum over $j$ ud $i$. We use a new variable $k = i + j$ to concentrate on the total exponent $x^k$. Therefore, we have to consider all contributions $i = \left[0,..., k \right]$ to the exponent $k$:
\begin{align}
    h(x) = \sum_{k=0}^{\infty} \left( \sum_{i=0}^{k} a_i b_{k-i} \right) x^k
\end{align}
If we compare this result with the form of a generating function of $h(x)$, we obtain the coefficients
\begin{align}
    c_k = \sum_{i=0}^{k} a_i b_{k-i}
\end{align}
This is exactly the definition of the discrete convolution $c = a * b$ of two coefficients $\{a_k\}$ and $\{b_k\}$.

\section*{9.3 Entropy and Lagrange multipliers}
We use the method of Lagrange multipliers with the following constraints:
\begin{align}
& \text{normalization: } g_1(p_c) = \sum_{c\in\Omega} p_c - 1 = 0 \\
& \text{expectation value: } g_2(p_c) = \sum_{c\in\Omega} p_c \chi_c - \bar{\chi} = 0
\end{align}
With the Lagrange multipliers $\alpha$ and $\beta$, we write down the Lagrange function
\begin{align}
L(p_c, \alpha, \beta) = -\sum_{c\in\Omega} p_c \ln p_c - \alpha \left( \sum_{c\in\Omega} p_c - 1 \right) - \beta \left( \sum_{c\in\Omega} p_c \chi_c - \bar{\chi} \right)
\end{align}
We differentiate $\frac{\partial L}{\partial p_c}=0$ to calculate the maximum:
\begin{align}
\frac{\partial L}{\partial p_c} = -(\ln p_c + 1) - \alpha - \beta \chi_c = 0
\end{align}
The probabilities $p_c = e^{-(1+\alpha)} e^{-\beta \chi_c}$ have to fullfill the normalization constraint:
\begin{align}
    \sum_{c\in\Omega} e^{-(1+\alpha)} e^{-\beta \chi_c} = 1 \implies e^{-(1+\alpha)} \sum_{c\in\Omega} e^{-\beta \chi_c} = 1
\end{align}
This result leads to the definition of the canonical partition function:
\begin{align}
    Z = \sum_{c\in\Omega} e^{-\beta \chi_c}
\end{align}
With this notation, we obtain the normalized and well known Boltzmann distribution from statistical physics.
\begin{align}
    p_c = \frac{1}{Z} e^{-\beta \chi_c} \quad
\end{align}

\section*{9.4 Differential entropy}
\subsection*{(a) and (b)}
The discretized Shannon entropy
$$H = - \sum_{j=-\infty}^{\infty} p_j \ln p_j = - \sum_{j=-\infty}^{\infty} \left[ p(j \Delta x) \Delta x \right] \ln \left[ p(j \Delta x) \Delta x \right]$$
can be seperated into two parts
$$H = - \sum_{j=-\infty}^{\infty} p(j \Delta x) \ln p(j \Delta x) \Delta x - \sum_{j=-\infty}^{\infty} p(j \Delta x) \ln \Delta x \Delta x$$

The first term is the definition of the continous differential entropy for $\Delta x \approx 0$
$$\lim_{\Delta x \to 0} \left( - \sum_{j=-\infty}^{\infty} p(j \Delta x) \ln p(j \Delta x) \Delta x \right) = - \int_{-\infty}^{\infty} p(x) \ln p(x) \, dx = H_c$$

The second term will end up as the offset $\Delta H$. We can pull out $\ln \Delta x$ of the sum and use the normalization condition for the probability density:
$$\lim_{\Delta x \to 0} \left( - \ln \Delta x \sum_{j=-\infty}^{\infty} p(j \Delta x) \Delta x \right) = - \ln \Delta x \int_{-\infty}^{\infty} p(x) \, dx = - \ln \Delta x \cdot 1$$

All together, we obtain the result vor (a):
$$H = H_c - \ln \Delta x$$

The offset $\Delta H := H - H_c$ is dominated by the logarithm of $\Delta x$
$$\Delta H = - \ln \Delta x $$
This is the result for task (b).

\subsection*{(c)}

The offset $\Delta H$ diverges in the limit $\Delta x \to 0$, which corresponds to an infinitely fine spatial resolution. The underlying reason is the infinite information content of the continuum: since a continuous variable possesses infinitely many potential states, an infinite amount of information (or entropy) is required to describe the system's state with absolute precision.
