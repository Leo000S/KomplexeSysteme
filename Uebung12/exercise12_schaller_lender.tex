\section*{12.1: The First Gap}
\subsection*{(a)}

For the Ising quantum chain, the first gap represents the lowest elementary excitation.
It depends on $\lambda$ and a gapless state is possible. The gapless state - where the correlation length diverges - is also called quantum critical point or quantum phase transition, as it is the point between the degenerate, ordered and the nondegenerate, disordered phase (for both phases $\Delta_N>0$).

Thus the first gap measures how far the system is from criticality.

\subsection*{(b)}
We used Python for this task. 
\begin{minted}{python}
import numpy as np

def get_ising_hamiltonian(N, lam):
#pauli matrices
    sx = np.array([[0, 1], [1, 0]], dtype=complex)
    sz = np.array([[1, 0], [0, -1]], dtype=complex)
                 
#construct 2^N x 2^N matrix representing an operator acting on a specific site
    def get_site_operator(op, site):
        mat = np.array([[1.0]], dtype=complex)
        for i in range(N):
            if i == site:
                mat = np.kron(mat, op)
            else:
                mat = np.kron(mat, np.eye(2))
        return mat

    H = np.zeros((2**N, 2**N), dtype=complex)
    
    for n in range(N):
#periodic boundary conditions
        next_n = (n + 1) % N
        
#interaction term: sigma^x_n * sigma^x_{n+1}
        term_x = get_site_operator(sx, n) @ get_site_operator(sx, next_n)
        
#transverse field term: lambda * sigma^z_n
        term_z = lam * get_site_operator(sz, n)
        
        H += term_x + term_z
        
    return H

#cross check
H_3 = get_ising_hamiltonian(N=3, lam=0.8)
eigenvalues = np.linalg.eigvalsh(H_3)
print("Eigenvalues for N=3, lambda=0.8:\n", np.round(eigenvalues, 4))
\end{minted}

\subsection*{(c)}
We expand the code from (b) with 
\begin{minted}{python}
import numpy as np
import matplotlib.pyplot as plt
Ns = [2, 4, 6, 8, 10, 12]
lambdas = [0.8, 1.0, 1.2]

#dictionary to hold computed gaps
gaps_dict = {lam: [] for lam in lambdas}

#compute gaps
for lam in lambdas:
    print(f"Computing gaps for lambda = {lam}...")
    for N in Ns:
        H = get_ising_hamiltonian(N, lam)

        #compute eigenvalues for a hermitian matrix
        eigenvalues = np.linalg.eigvalsh(H)

        eigenvalues = np.sort(eigenvalues)

        #difference between the lowest two eigenvalues
        gap = eigenvalues[1] - eigenvalues[0]
        gaps_dict[lam].append(gap)

#plotting double-log
plt.figure(figsize=(8, 6))

for lam in lambdas:
    plt.loglog(Ns, gaps_dict[lam], 'o-', label=f'$\lambda = {lam}$')

plt.xlabel('System Size (N)')
plt.ylabel('$\Delta_N$')
plt.xticks(Ns, [str(n) for n in Ns])

import numpy as np
Ns = [2, 4, 6, 8, 10, 12]
lam = 1.0
gaps = {}

# 1. Compute all required gaps at the critical point lambda = 1
for N in Ns:
    H = get_ising_hamiltonian(N, lam)
    eigenvalues = np.linalg.eigvalsh(H)
    gap = eigenvalues[1] - eigenvalues[0]
    gaps[N] = gap

# 2. Compute the negative discrete logarithmic derivative nu(N)
print(f"{'N':<5} | {'nu(N)':<10}")
print("-" * 18)

for N in [2, 4, 6, 8, 10]:
    delta_N = gaps[N]
    delta_N_plus_2 = gaps[N + 2]

    # Formula: nu(N) = -ln[Delta_(N+2) / Delta_N] / ln[(N+2)/N]
    nu_N = -np.log(delta_N_plus_2 / delta_N) / np.log((N + 2) / N)

\section*{12.2: DP mean field approximation}
\subsection*{(a)}
For a homogeneous ($\nabla^2\rho = 0$) and stationary ($\dot{\rho} = 0$) state, the equation simplifies to:
\begin{equation}
    0 = \lambda\rho_{\text{stat}}(1 - \rho_{\text{stat}}) - \rho_{\text{stat}} = \rho_{\text{stat}} \left[ \lambda(1 - \rho_{\text{stat}}) - 1 \right]
\end{equation}
We obtain two distinct fixed points $\rho^*$:
\begin{align}
    \rho_1^* &= 0 \\
    \rho_2^* &= 1 - \frac{1}{\lambda}
\end{align}
Since density must be non-negative ($\rho \ge 0$), the active solution $\rho_2^*$ exists for $\lambda \ge 1$. Consequently, the critical point is:
\begin{equation}
    \lambda_c = 1
\end{equation}

To test the stability, we define the the function $\dot{\rho}(t) = f(\rho) = (\lambda - 1)\rho - \lambda\rho^2$. We introduce a small perturbation $\epsilon(t)$ around a fixed point $\rho^*$ ($\rho = \rho^* + \epsilon(t)$). With this, we can write the differential equation
\begin{equation}
    \dot{\rho}(t) = \frac{d}{dt} (\rho^* + \epsilon(t)) = f(\rho^* + \epsilon(t)) \approx f(\rho^*) + \frac{df}{d \rho} \epsilon(t) = \frac{df}{d \rho}  \epsilon(t) \text{ ,}
\end{equation}
where we have used the Taylor approximation and that $\rho^*$ is a fixed point ($f(\rho^*)=0$). The derivative of $f(\rho)$ is:
\begin{equation}
    f'(\rho) = \frac{\partial f}{\partial \rho} = \lambda - 1 - 2\lambda\rho
\end{equation}
We can now conclude from the derivation above, that
\begin{equation}
    \dot{\rho}(t) = \frac{d}{dt} (\rho^* + \epsilon(t))=\dot{\epsilon}(t) = \frac{d}{d \rho} f \epsilon(t)
\end{equation}
This means, that we need a negative derivative $\frac{d}{d \rho} f$ to have a stable state, because then the pertubation $\epsilon$ will get smaller. We look at all possible combination for the stationary densities:
\begin{itemize}
    \item \text{For $\rho_1^* = 0$:}
    \begin{equation}
        f'(0) = \lambda - 1
    \end{equation}
    If $\lambda < \lambda_c = 1$, then $f'(0) < 0 \implies$ \text{Stable}.\\
    If $\lambda > \lambda_c = 1$, then $f'(0) > 0 \implies$ \text{Unstable}.

    \item \text{For $\rho_2^* = 1 - \frac{1}{\lambda}$ (defined only for $\lambda > 1$):}
    \begin{equation}
        f'\left(1 - \frac{1}{\lambda}\right) = \lambda - 1 - 2\lambda\left(1 - \frac{1}{\lambda}\right) = 1 - \lambda
    \end{equation}
    Since $\lambda > 1$, it follows that $f'(\rho_2^*) < 0$ always holds in this regime $\implies$ \text{Stable}.
\end{itemize}

\subsection*{(b)}
From part (a), we know that for the active phase ($\lambda > \lambda_c = 1$), the stable stationary density is:
\begin{equation}
    \rho_{\text{stat}} = 1 - \frac{1}{\lambda} = \frac{\lambda - 1}{\lambda}
\end{equation}

To find the scaling behavior very close to the critical point, we conduct a Taylor expansion around the point $\lambda=\lambda_c=1$, we find the scaling in first order:
\begin{equation}
    \rho_{\text{stat}}(\lambda) = \rho(1)+\rho'(1)(\lambda-1) +\frac{\rho''(1)}{2!}(\lambda-1)^2+...\approx 0+ \frac{1}{1^2}(\lambda-1) = \left( \lambda - 1 \right)^1
\end{equation}

By comparing this result with the scaling relation $\rho_{\text{stat}} \sim (\lambda - 1)^\beta$, we find the critical exponent:
\begin{equation}
    \beta = 1
\end{equation}
\subsection*{(c)}
Setting $\lambda = 1$ and $\nabla^2\rho = 0$ in the mean-field equation, we obtain:
\begin{equation}
    \dot{\rho} = 1 \cdot \rho(1 - \rho) - \rho = \rho - \rho^2 - \rho = -\rho^2
\end{equation}
This is a separable ordinary differential equation:
\begin{equation}
    \frac{1}{\rho^2} d\rho = -dt
\end{equation}
Integrating both sides gives:
\begin{equation}
    -\frac{1}{\rho(t)} = -t + C \implies \rho(t) = \frac{1}{t - C}
\end{equation}
where $C$ is a constant of integration determined by the initial condition. In the long-time limit ($t \gg |C|$), the constant $C$ becomes negligible, yielding the asymptotic power-law decay:
\begin{equation}
    \rho(t) \approx t^{-1}
\end{equation}
We find the critical decay exponent $\delta = 1$

\subsection*{(d)}
At the critical point $\lambda = 1$, the mean-field equation is given by:
\begin{equation}
    \frac{\partial \rho}{\partial t} = -\rho^2 + D \frac{\partial^2 \rho}{\partial x^2}
\end{equation}
We test the scaling ansatz for the Green's function $\rho(x,t) = G(x,t) = t^{-1} f(\eta)$ with the variable $\eta = \frac{x^2}{t}$. First, we compute the required partial derivatives for $t > 0$:

\begin{enumerate}
    \item
    \begin{equation}
        \frac{\partial G}{\partial t} = -t^{-2} f(\eta) + t^{-1} f'(\eta) \frac{\partial \eta}{\partial t} = -t^{-2} f(\eta) + t^{-1} f'(\eta) \left( -\frac{x^2}{t^2} \right) = -t^{-2} \left[ f(\eta) + \eta f'(\eta) \right]
    \end{equation}

    \item
    \begin{equation}
        \frac{\partial G}{\partial x} = t^{-1} f'(\eta) \frac{\partial \eta}{\partial x} = t^{-1} f'(\eta) \left( \frac{2x}{t} \right) = 2x t^{-2} f'(\eta)
    \end{equation}
    \begin{equation}
        \frac{\partial^2 G}{\partial x^2} = t^{-2} \frac{\partial}{\partial x} \left( 2x f'(\eta) \right) = t^{-2} \left[ 2 f'(\eta) + 4\frac{x^2}{t} f''(\eta) \right] = t^{-2} \left[ 2 f'(\eta) + 4\eta f''(\eta) \right]
    \end{equation}

    \item
    \begin{equation}
        G^2 = t^{-2} f(\eta)^2
    \end{equation}
\end{enumerate}

Substituting these derivatives back into the partial differential equation, we obtain:
\begin{equation}
    -t^{-2} \left[ f(\eta) + \eta f'(\eta) \right] = -t^{-2} f(\eta)^2 + D t^{-2} \left[ 2 f'(\eta) + 4\eta f''(\eta) \right]
\end{equation}
Since $t > 0$, we can eliminate any explicit time dependence:
\begin{equation}
    f(\eta) + \eta f'(\eta) = f(\eta)^2 - 2D f'(\eta) - 4D\eta f''(\eta)
\end{equation}
Rearranging the terms leads to an autonomous ordinary differential equation for $f(\eta)$:
\begin{equation}
    4D\eta f''(\eta) + (2D + \eta) f'(\eta) + f(\eta) - f(\eta)^2 = 0
\end{equation}
Because the differential equation is now written purely in terms of $\eta = x^2/t$ for the function $f(\eta)$, the scaling transformation is proven.
