\section*{11.1: Entanglement of a pure 2-qubit state}
\subsection*{(a)}

We calculated the matrix and verified it's purity (the trace of it's square has to be one) in python with this code:

\begin{minted}{python}
import sympy as sp
i = sp.I
sqrt2 = sp.sqrt(2)

psi = sp.Matrix([
    sp.Rational(1, 5),
    (2 * i * sqrt2) / 5,
    sp.Rational(-4, 15),
    (-8 * i * sqrt2) / 15])

rho = psi * psi.H

print("latex code")
print(sp.latex(rho))

rho_squared = rho**2
purity = rho_squared.trace()

print("purity")
print(f"Tr(rho²) = {purity}")
\end{minted}

\begin{align}
\rho=
    \begin{pmatrix}
    \frac{1}{25} & - \frac{2 \sqrt{2} i}{25} & - \frac{4}{75} & \frac{8 \sqrt{2} i}{75}\\[0.1cm]
    \frac{2 \sqrt{2} i}{25} & \frac{8}{25} & - \frac{8 \sqrt{2} i}{75} & - \frac{32}{75}\\[0.1cm]
    - \frac{4}{75} & \frac{8 \sqrt{2} i}{75} & \frac{16}{225} & - \frac{32 \sqrt{2} i}{225}\\[0.1cm]
    - \frac{8 \sqrt{2} i}{75} & - \frac{32}{75} & \frac{32 \sqrt{2} i}{225} & \frac{128}{225}
    \end{pmatrix}
\end{align}

\begin{align}
    \text{Tr}(\rho^2)=1

\subsection*{(b)}

We calculated the reduced matrices with the by carrying out the partial traces in python:
\begin{minted}{python}
import sympy as sp

i = sp.I
sqrt2 = sp.sqrt(2)

psi = sp.Matrix([
    sp.Rational(1, 5),
    (2 * i * sqrt2) / 5,
    sp.Rational(-4, 15),
    (-8 * i * sqrt2) / 15
])
rho = psi * psi.H

rho_L = sp.Matrix([
    [rho[0,0] + rho[1,1], rho[0,2] + rho[1,3]],
    [rho[2,0] + rho[3,1], rho[2,2] + rho[3,3]]
])

rho_R = sp.Matrix([
    [rho[0,0] + rho[2,2], rho[0,1] + rho[2,3]],
    [rho[1,0] + rho[3,2], rho[1,1] + rho[3,3]]
])

print("rho_L")
print(sp.latex(rho_L))
print("\n rho_R")
print(sp.latex(rho_R))
\end{minted}

\begin{align}
    \rho_L=
    \begin{pmatrix}
    \frac{9}{25} & - \frac{12}{25}\\
    - \frac{12}{25} & \frac{16}{25}
    \end{pmatrix} \hspace{1cm}
    \rho_R=
    \begin{pmatrix}\frac{1}{9} & - \frac{2 \sqrt{2} i}{9}\\\frac{2 \sqrt{2} i}{9} & \frac{8}{9}\end{pmatrix}
\end{align}

\subsection*{(c)}
A pure state is called entangled if the reduced density matrices are mixed. To check if $\rho$ is entangle we simply check, if the reduced density matrices are pure.
With Python (code similar to the code above) we calculated:
\begin{align}
        \text{Tr}(\rho_L^2)=1
        \text{Tr}(\rho_R^2)=1
\end{align}
This means, $\rho$ is not entangled.

\section*{11.2: Quantum Cryptography}
\subsection*{(a)}
We distinguish the four possible combinations of Alice's preparation and Bob's measurement:

\begin{itemize}
    \item two options for a=b: 
    
    (1) \textbf{Case $a=0$, $b=0$:} Alice sends $|0\rangle$ and Bob measures with $M_0$. Since
    \[
    M_0|0\rangle = |0\rangle,
    \]
    
    (2) \textbf{Case $a=1$, $b=1$:} Alice sends $|+\rangle$ and Bob measures with $M_1$. Since
    \[
    M_1|+\rangle = |+\rangle,
    \]
    
    In both cases, the outcome is always $m=+1$.

    \item two options for a $\neq$ b
    
    (1) \textbf{Case $a=0$, $b=1$:} Alice sends $|0\rangle$ and Bob measures with $M_1$. Using
    \[
    |0\rangle=\frac{|+\rangle+|-\rangle}{\sqrt{2}},
    \]
    
    (2) \textbf{Case $a=1$, $b=0$:} Alice sends $|+\rangle$ and Bob measures with $M_0$. Since
    \[
    |+\rangle=\frac{|0\rangle+|1\rangle}{\sqrt{2}},
    \]
    
    In both cases the outcome $m=-1$ occurs with the probability $1/2$.
\end{itemize}
 
Therefore, the outcome $m=-1$ is only possible if a $\neq$ b. Since a and b are either 0 or 1, this is equivalent to 
\[
\boxed{a=1-b.}
\]
\subsection*{(b)}
A key bit is obtained only in rounds where Bob obtains the outcome $m=-1$,
since only then Alice and Bob can conclude from part (a) that $a=1-b$.
We compute the success probability by using the cases from part (a).

Each pair $(a,b)$ occurs with probability $1/4$. From part (a), we know that
\[
P(m=-1 \mid a=0,b=0)=0,\qquad P(m=-1 \mid a=1,b=1)=0,
\]
while
\[
P(m=-1 \mid a=0,b=1)=\frac{1}{2},\qquad P(m=-1 \mid a=1,b=0)=\frac{1}{2}.
\]

Hence, the total success probability is
\[
P(m=-1)=\frac{1}{4}\cdot 0 + \frac{1}{4}\cdot \frac{1}{2}
+ \frac{1}{4}\cdot \frac{1}{2} + \frac{1}{4}\cdot 0
= \frac{1}{4}.
\]

Since each transmission uses one qubit,
the average number of qubits needed to obtain one successful key bit is the
inverse of the success probability:
\[
\boxed{\langle N \rangle = \frac{1}{P(m=-1)} = 4.}
\]

\subsection*{(c)}
Eve performs a measurement in the orthonormal basis
\[
|\phi_+\rangle=\alpha|0\rangle+\beta|1\rangle,\qquad
|\phi_-\rangle=\beta^*|0\rangle-\alpha^*|1\rangle,
\]
with
\begin{align}
    |\alpha|^2+|\beta|^2&=1\\
    u:=|\alpha|^2 \hspace{1cm}& v=\frac{1}{2}|\alpha+\beta|^2\\
    \Rightarrow |\beta|^2=1-u \hspace{1cm}& \frac{1}{2}|\alpha-\beta|^2=1-v
\end{align}    
After Eve's measurement, the state collapses to
$|\phi_\pm\rangle$ and is measured by Bob. The resulting
probabilities are obtained with the following calculations.

Consider the case where Alice sends $|0\rangle$ and Bob measures
with $M_0$. The probabilities of obtaining the outcome $m=-1$ for $a=b$ are
\begin{align}
P(m=-1|a=b=0)
&=|\langle\phi_+|0\rangle|^2\,|\langle1|\phi_+\rangle|^2
+|\langle\phi_-|0\rangle|^2\,|\langle1|\phi_-\rangle|^2\\
&=|\alpha|^2|\beta|^2+|\beta|^2|\alpha|^2\\
&=2|\alpha|^2|\beta|^2\\
&=2u(1-u)\\[0.5cm]
P(m=-1|a=b=1)
&=|\langle\phi_+|+\rangle|^2\,|\langle-|\phi_+\rangle|^2
+|\langle\phi_-|+\rangle|^2\,|\langle-|\phi_-\rangle|^2\\
&=\frac{1}{4}|\alpha+\beta|^2|\alpha-\beta|^2+\frac{1}{4}|\alpha-\beta|^2|\alpha+\beta|^2\\
&=\frac{1}{2}|\alpha+\beta|^2|\alpha-\beta|^2\\
&=2v(1-v)
\end{align}

The probabilities of obtaining the outcome $m=-1$ for $a\neq b$ are

\begin{align}
P(m=-1|a=0, b=1)
&=|\langle\phi_+|0\rangle|^2\,|\langle-|\phi_+\rangle|^2
 +|\langle\phi_-|0\rangle|^2\,|\langle-|\phi_-\rangle|^2\\
&=\frac12|\alpha|^2|\beta-\alpha|^2
+\frac12|\beta|^2|\beta+\alpha|^2\\
&=u+v-2uv\\[0.5cm]
P(m=-1|a=1, b=0)
&=|\langle\phi_+|+\rangle|^2\,|\langle1|\phi_+\rangle|^2
 +|\langle\phi_-|+\rangle|^2\,|\langle1|\phi_-\rangle|^2\\
&=\frac12|\alpha+\beta|^2|\beta|^2
+\frac12|\alpha-\beta|^2|\alpha|^2\\
&=u+v-2uv\\
\end{align}

We see that Eve modifies Bob's measurement statistics, which depend only on the two parameters $u=|\alpha|^2$ and $v=\frac12|\alpha+\beta|^2$.

\subsection*{(d)}
Alice and Bob will not recognize the intervention of Eve, if the statistics stay the same.
To obtain the same statistic, we have two conditions for the probabilities:
\begin{align}
P(m=-1\,|\,a=b=0)=2u(1-u) = 0 
\intertext{$\Rightarrow$ $u=1$ or $u=0$}
P(m=-1\,|\,a=b=1)=2v(1-v) = 0
\intertext{$\Rightarrow$ $v=1$ or $v=0$}
P(m=-1\,|\,a\neq b)= v + u - 2 u v = 0.5
\intertext{$\Rightarrow$ $v=u=\frac12$ or $v=\frac12$ and $u=0$ or $v=0$ and $u=\frac12$}
\end{align}

This shows, that it's not possible to find any values for $u$ and $v$, where the probabilities for every outcome will stay the same and thus where the interception isn't detectable.

\subsection*{(e)}
(d) showed, that it is impossible for Eve to gain any information about the key, without altering the statistics, i.e., being detected.
